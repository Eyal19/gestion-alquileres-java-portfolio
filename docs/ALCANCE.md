# Alcance del portafolio

Documentación y capturas revisadas de Gestión de Alquileres 1.2.3.
No contiene fuentes Java, ejecutables, JAR, base de datos, respaldos ni implementación criptográfica.
No se seleccionaron fragmentos de código: la arquitectura, las pruebas y las pantallas muestran
el trabajo sin revelar la implementación del sistema.

El proyecto demuestra aprendizaje aplicado y capacidad para resolver y documentar problemas.
No se afirma experiencia senior, despliegue empresarial, certificación de seguridad ni cobertura completa.
La preparación para Git no implica que el original ya se mantuviera con Git.
